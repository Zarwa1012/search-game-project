**Word Search Adventure**

Welcome to Word Search Adventure, an exciting puzzle game developed entirely in C++! Challenge your mind by searching for hidden words across four different categories. Test your vocabulary, concentration, and problem-solving skills as you uncover every hidden word.

 Features

*   Four exciting categories to explore
*   Hidden word search puzzles
*  Error messages for incorrect answers
*  Congratulations message upon successful completion
*  Enhances vocabulary and observation skills
*  Built completely using C++
  Categories

* Animals
* Fruits
* Technology
* Countries

How to Play

1. Choose a category.
2. Search the puzzle grid for hidden words.
3. Enter the words you find.
4. Incorrect entries will display an error message.
5. Find all the words to receive a congratulatory message and win the game.

 Objective

Explore, discover, and find every hidden word in the puzzle. Complete the challenge and become a Word Search Champion!

Search Smart • Think Fast • Have Fun!
